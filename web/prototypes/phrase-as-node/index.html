What this lands. Same instrument, same verdict file — the sense-SET selection rides into the verdict as apt_synset_ids (already the shape mf-grade-sensecheck POSTs for a split), and a no-synset phrase rides as endpoint_ref: "vec:pressed_flower" instead of a synset id. A plain single-word node is just a sense-SET of size 1 with a syn: ref — the old corpus reads unchanged. One verdict can yield several sense-keyed edges: that's generative richness for the compositor, not a disambiguation chore.
