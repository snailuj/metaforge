# Forge Reader — back-of-the-napkin triage

**Batch:** 876 chains, all abstract/emotional topics → concrete vehicles.
**Verdict:** ~170 hits (7+), roughly a 1-in-5 strike rate, spread across 69 of the ~90 topics. That's a *good* slush pile — most topics throw at least one keeper, and the keepers cluster where the generator reached for a specific, named, slightly technical object instead of the nearest mood-word.

The batch has a house style: topic → mood → concrete-noun, four hops, very competent, occasionally electric. The failure mode is never incoherence — it's *blandness*. When it dies, it dies on a cliché vehicle (fire, storm, wound, ghost, drowning, fever, hearth) or a synonym-walk. When it sings, it's because the vehicle is a *named thing with mechanics* — verdigris, moraine, dead letter, taxidermy, cargo cult, Potemkin village, annealing, tidemark.

## Standout linkages (steal these)

1. **delusion ⇒ Potemkin village** — false prosperity → painted facade → hollow settlement → Potemkin village. The single best in the batch: a whole fake town as self-deception. **8**
2. **delusion ⇒ cargo cult** — misread causality → ritual replica → cargo cult. Believing the form summons the substance. **8**
3. **hypocrisy ⇒ taxidermy** — dead interior → lifelike shell → taxidermy. A virtue mounted and stuffed. Nasty, perfect. **8**
4. **envy ⇒ verdigris** — copper surface → green patina → verdigris. Envy literally *is* the green that corrosion leaves on metal. Inevitable-in-hindsight. **8**
5. **loneliness ⇒ moraine** — retreat of others → left-behind debris → moraine. What the glacier leaves when it withdraws. Quietly devastating. **8**
6. **ostracism ⇒ dead letter** — undeliverable address → dead letter. A person as mail that can never arrive. **8**
7. **propaganda ⇒ ventriloquism** — fabricated voice → puppet speech → ventriloquism. The state's mouth on someone else's body. **8**
8. **wistfulness ⇒ tidemark** — the shape left by absence → receded water's mark → tidemark. Longing as the stain a vanished tide leaves. **8**
9. **ambivalence ⇒ palindrome / counterpoint** — reads the same both ways / two voices in harmonic tension. Two genuinely fresh structural images for being-of-two-minds. **8**
10. **feud ⇒ fermentation** — grievance → suppressed bitterness → pressure → fermentation. A feud souring under its own pressure. (Also: **nostalgia ⇒ palimpsest** — memory overwritten on memory.) **8**

## Deadest — deprioritise

Pure dead metaphors the eye slides off:
- serenity ⇒ still water / sky (**2**) — the definition of inert.
- anger-family ⇒ fire/storm/volcano (wrath ⇒ volcano, dread ⇒ storm, foreboding ⇒ storm) (**2–3**).
- *anything* ⇒ wound (resentment, remorse, anguish, infatuation→fever) — dead on arrival (**2**).
- *anything* ⇒ ghost / hearth / drowning (nostalgia⇒ghost, hospitality⇒hearth, intimacy⇒hearth) (**2–3**).
- **`undertow`** is the batch's worst tic: it's bolted onto ~14 different topics (longing, dread, anguish, despair, remorse, envy, premonition, curiosity, delirium, stupor, scandal, feud…). Always coherent, always flat. Cap it at one or two topics and kill the rest.

## Patterns worth knowing

- **Topics that go LIVE reliably:** the *cognitive/social-machinery* ones — delusion, hypocrisy, propaganda, scepticism, insight, concentration, foresight, ambivalence, ostracism, conformity, diplomacy, truce. These pull specific instruments (assay, crucible, actuary, orrery, escrow, caesura, acupuncture, bonsai) and that specificity is the liveness.
- **Topics that go DEAD reliably:** the *big primary emotions* — serenity, wrath, despair, gratitude, virtue, scandal. The generator reaches for the canonical dead metaphor every culture already has, so the vehicle is pre-worn.
- **Vehicle = named technical object ⇒ usually a hit.** Vehicle = elemental noun (fire/water/stone/storm/light) ⇒ usually dead.
- **Concrete-craft verbs win:** annealing, winnowing, panning, rendering, elision, decipherment, triangulation — process-vehicles land because they smuggle in mechanism. Lift these for "the work of X" lines.
- **Body-horror & decay vehicles punch above weight:** gangrene, necrosis, calcification, moulting, taxidermy, vivisection — genre readers eat these up; don't sand them down.
- **Repeated vehicles to ration:** amber (preserved-moment, used ~18×), palimpsest, mycelium, fermentation. Each is a hit *once*; by the tenth topic it's wallpaper. Diversify or the forge will feel like it only knows six tricks.
