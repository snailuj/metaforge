# data-pipeline/grading/

Persistent JSONL store for the Metaphor Grading Tool bootstrap loop.
All files use `_provisional` filename markers — they accumulate across sessions and rounds.

---

## Files

| File | Description |
|------|-------------|
| `sonnet_chains_provisional_r<N>.jsonl` | Per-round chain proposals generated by Sonnet. One line per chain. Round files accumulate — never overwrite a previous round. |
| `judgements_provisional.jsonl` | Append-only verdict log. One line per submitted judgement. Never hand-edit; later judgements on the same chain supersede earlier ones (resolved at read-time by the sidecar). |
| `design_notes_provisional.md` | Append-only cross-session notes. Each POST via the sidecar appends a timestamped block. Plain Markdown; readable in any editor. |

**Do not hand-edit `sonnet_chains_provisional_r*.jsonl` or `judgements_provisional.jsonl`.**
Both files are parsed strictly against their schemas by `validate_grading_jsonl.py` — a corrupted line breaks the sidecar's read path.

---

## Schemas

### chain.v1

One chain record (one JSONL line in `sonnet_chains_provisional_r*.jsonl`):

```json
{
  "schema_version": "chain.v1",
  "topic": "anger",
  "topic_synset_id": "30227",
  "vehicle": "volcano",
  "vehicle_synset_id": "79695",
  "proposer": "sonnet_v1",
  "round": 1,
  "chain": [
    {"phrase": "anger",           "head": "anger",    "synset_id": "30227"},
    {"phrase": "pressure",        "head": "pressure", "synset_id": "60988"},
    {"phrase": "subterranean heat","head": "heat",     "synset_id": "63717"},
    {"phrase": "magma",           "head": "magma",    "synset_id": "102551"},
    {"phrase": "volcano",         "head": "volcano",  "synset_id": "79695"}
  ],
  "chain_signature": "9ea3c79fdf724c66b1808f9beaa13be92cd3996a2baed39be70f4bade3e6eba0",
  "generated_at": "2026-05-30T00:00:00Z"
}
```

**Invariants:**
- `chain[0]` must match `topic` / `topic_synset_id` (endpoint canonicalisation).
- `chain[-1]` must match `vehicle` / `vehicle_synset_id`.
- `chain_signature` = `sha256(":".join([proposer] + [nfc_lower(p) for p in phrases]))` — stable across snap-drift and head re-extraction.
- `synset_id` on intermediate steps may be `null` if a step has not been snapped.

### judgement.v1

One judgement record (one JSONL line in `judgements_provisional.jsonl`):

```json
{
  "schema_version": "judgement.v1",
  "ts": "2026-05-30T12:34:56Z",
  "judged_by": "julian",
  "round": 1,
  "topic": "anger",
  "topic_synset_id": "30227",
  "vehicle": "volcano",
  "vehicle_synset_id": "79695",
  "proposer": "sonnet_v1",
  "chain_signature": "9ea3c79fdf724c66b1808f9beaa13be92cd3996a2baed39be70f4bade3e6eba0",
  "label": "live",
  "confidence": "high",
  "notes": "",
  "supersedes_ts": null
}
```

**Labels:** `live` | `dead` | `bad_path` | `irrelevant`

**Confidence:** `high` | `med` | `low`

**Superseding:** if a judgement is revised, a new record with `supersedes_ts` pointing at the original `ts` is appended. The sidecar resolves latest-wins at read-time; the old record is never deleted.

## Running the sidecar locally

```bash
cd /home/agent/projects/metaforge
GRADING_DEV=1 METAFORGE_GRADING_DEV_OK=1 \
    data-pipeline/.venv/bin/python -m grading_sidecar.main
```

Then verify:

```
http://localhost:53775/api/grading/healthz
```

`GRADING_DEV=1` bypasses the `X-Grading-Secret` header check and the host-allowlist middleware.
`METAFORGE_GRADING_DEV_OK=1` suppresses the prod-safety assertion that rejects `GRADING_DEV` outside an explicit dev context.

---

## Validating the data

```bash
data-pipeline/.venv/bin/python data-pipeline/scripts/validate_grading_jsonl.py
```

Reads all `sonnet_chains_provisional_r*.jsonl` and `judgements_provisional.jsonl` under `data-pipeline/grading/`, validates each line against its schema, and reports any violations.

## Installing the pre-commit secret-scan hook

```bash
ln -sf "$(pwd)/scripts/pre_commit_secret_scan.py" .git/hooks/pre-commit
chmod +x .git/hooks/pre-commit
```

The hook scans staged changes for high-entropy strings (credentials, API keys) before every commit.
It will block a commit if a secret-like pattern is detected — intentional; secrets must never land in this repo.

## Notes

- **No secrets in `design_notes_provisional.md`.** This file is committed to a public repo. Notes are plain observations, failure-mode labels, and prompt ideas — not credentials, not env-var values, not anything operational.
- **Round files accumulate.** `sonnet_chains_provisional_r1.jsonl` is never overwritten when round 2 arrives; `r2.jsonl` is added alongside it. The sidecar's `GET /api/grading/chains?topic=…` unions all round files.
- **Auto-commit timer.** While the sidecar is running it commits `data-pipeline/grading/` to git every 15 minutes. If the sidecar is stopped mid-session, run `git add data-pipeline/grading/ && git commit -m "chore: manual grading flush"` to preserve unsaved judgements.
- **Bootstrap loop is iterative.** After enough round-1 grading, run `build_next_round_prompt.py` (feeds `bad_path` examples into the next Sonnet prompt) and `grading_diagnostics.py` (Wilson-CI convergence check) before deciding whether to fire round 2.

See the authoritative design: `docs/superpowers/specs/2026-05-30-metaphor-grading-tool-design.md`.
