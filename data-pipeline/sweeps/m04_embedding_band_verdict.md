## Operator Interpretation (post-run)

The auto-generated "ratify" verdict above is **misleading** — it triggers
because `best.separation_score == baseline.separation_score` (both 0.0258),
which the writer's logic treats as "non-regressive → ratify". Three signals
indicate the sweep produced no actionable information:

1. **All 9 cells produce identical numbers.** d_min and d_max variations
   moved nothing. Either the embedding path doesn't generate
   different candidates across the band, or the band doesn't matter for
   this cohort, or both.
2. **`embedding: 0` and `both: 0` across every cell.** The embedding path
   didn't contribute a single apt-pair hit. All 6 hits came from the
   cluster path — identical to baseline.
3. **`apt_missing: 194/200 = 97%` and `inapt_missing: 197/200 = 98.5%`.**
   The vast majority of MUNCH pairs cannot be resolved by the API at all
   (the vehicle isn't appearing in /forge/suggest within limit=50).

### Root cause: MUNCH is the wrong cohort for M04

MUNCH is a paraphrase-style metaphor set — pairs like (`approach`,
`direction`) where the "metaphor" is a within-domain synonym. M04's
cosine-band path is specifically designed to surface **cross-domain**
pairs (anger→fire, idea→light, time→money). The canary integration
test (`TestCascadeUnion_ClassicalPairsSurface_AsCandidates`) confirms
those classical pairs DO reach the scorer via the embedding path —
but MUNCH simply doesn't measure that surface.

This is exactly the cohort-trap the brainstorming phase warned about:
optimising against MUNCH would reify clichés, AND MUNCH doesn't even
contain the cross-domain class M04 targets. The sweep proved nothing
because the eval signal is orthogonal to the change.

### Operator verdict: keep `SourcesCluster` default

- **No code change to `DefaultCascadeConfig`.** The pre-sweep default
  (`SourcesCluster`) remains shipped. Users opt into union/embedding via
  the env var or CLI flag — both already wired and tested.
- **M04 v2 follow-up (PIPELINE.md):** construct a cross-domain eval
  cohort (Lakoff classics + their attested inapt controls). Re-run the
  sweep against THAT cohort. The current sweep harness + driver
  infrastructure is reusable; only the fixture changes.
- **M04 v1 ships value:** the binary generation lift is real (classical
  pairs surface as candidates, canary test pins it). The user-facing
  contract is "request union mode via env var to get cross-domain
  candidates" — that contract holds today.
